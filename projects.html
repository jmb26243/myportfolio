02 / INDIVIDUAL AI APPLICATION PROJECT

AI Prompt Lab

Developing a student-focused application for experimenting with prompts and evaluating AI responses.

First working slice completed
AI.
PROMPT EXPERIMENTATION RESPONSE EVALUATION PYTHON / FLASK

01. The Problem

Generative AI tools can produce different results depending on how a prompt is written. Students and beginners may benefit from a structured way to experiment with prompts, evaluate generated responses, and learn from their results.

02. My Approach

I began by developing a research website to investigate prompt engineering practices, identify user needs, compare possible technical approaches, and plan the application.

I then developed the first working application using Python and Flask. Users can create accounts, sign in, enter prompts and AI responses, evaluate results, and save experiments.

The application currently accepts pasted AI responses rather than connecting to an external AI service.

03. Technical Highlights

Python Flask SQLite SQLAlchemy Flask-Login Bootstrap Pytest Strategy Pattern
  • Implemented user registration and authentication.
  • Added sign-in and sign-out functionality.
  • Created an experiment submission workflow.
  • Evaluated responses using relevance, clarity, and completeness scores.
  • Calculated and stored an overall evaluation rating.
  • Saved experiment records in an SQLite database.
  • Compared a simple scoring function with the Strategy Pattern.
  • Created automated tests for authentication, experiments, and evaluation.

04. Testing & What I Learned

The first working slice passed all 13 automated tests in the latest reported test run. I also manually verified account creation, sign-in, experiment submission, database storage, and sign-out.

This project helped me connect user-centered planning with backend development. I gained experience working with authentication, databases, application architecture, design patterns, and automated testing.
